# VoidLance

A space combat game for Android.

**[Download VoidLance.apk](../../raw/main/VoidLance.apk)** — install directly, no Play Store.

Package `net.nexus.lance`. Android 8.0 (API 26) or newer.

## Source

Not in this repository. The build tree was not kept, and the APK is the only
surviving copy — so this repo ships the app itself rather than a decompile
that would not match what was actually written.
